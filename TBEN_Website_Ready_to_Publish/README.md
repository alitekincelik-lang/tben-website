# TBEN Website – Ready-to-Publish Package

## Included
- Responsive bilingual English/Turkish website
- TBEN SVG logo and favicon
- About, mission, values, network, membership-interest and contact sections
- Netlify-compatible membership-interest form
- Privacy Policy, Terms of Use and Cookie Policy
- SEO title/description, robots.txt and sitemap.xml
- Mobile navigation and language selector

## Fastest launch option: Netlify
1. Create or sign in to a Netlify account.
2. Choose **Add new site → Deploy manually**.
3. Drag this complete folder (or the ZIP contents) into Netlify.
4. In the site dashboard choose **Domain management → Add a domain → tben.uk**.
5. Netlify will show the exact DNS records to add where tben.uk is registered.
6. Enable HTTPS when DNS is connected.
7. Test the membership form. Netlify Forms will collect submissions.

## Alternative: cPanel / conventional hosting
Upload every file and folder into `public_html`.
The website will work immediately, but the membership form needs a form-processing service or a small server script. Do not rely on the Netlify form attributes on ordinary hosting.

## Important before public launch
- Confirm the wording describing TBEN's legal status.
- Replace or expand the contact address when ready.
- Add social links only after official accounts are confirmed.
- Add analytics only after updating cookie consent and policy.
- Test on mobile, desktop and both languages.
